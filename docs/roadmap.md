**2026-07-29 — Phase PD 완료.** 다음은 **P1 (인증 · 커플 스페이스)**.

5탭 + `/design`이 목업 데이터로 실제 렌더되며 lint/build 통과, 7개 라우트 × 3개 fixture 전부 200.

## Definition of Done — 시트 실측치 대조

**원본 시트 값을 그대로 입력해 수치가 일치하는지 대조한다. 이것이 이 프로젝트의 핵심 회귀 테스트다.**

목업 단계에서는 `?fixture=sheet`가 이 시드를 그대로 재현한다. 실제 DB가 붙은 뒤에도 같은 값을
입력해 아래 수치가 나오는지 확인한다.

### 시드
- 총 가용예산 26,000,000 / 결혼식 배분 13,000,000
- 결혼식 소분류 예산 합계 13,380,000 (상견례식사 400,000 · 청첩장모임 500,000 · 드레스 1,100,000 ·
  주례 1,000,000 · 스튜디오 스냅 710,000 + 가정값)

### 아직 확인 못 한 것

- **월별 타임라인 차트** — Recharts가 클라이언트에서 그려져 SSR HTML에 없다. 브라우저로 직접 확인 필요.
- **터치 타깃 실측** — CSS 규칙 수준(`h-11`=44px, `min-h-14`=56px)은 확인했으나 렌더된 높이를 DOM에서 재지는 않았다.
- **Pretendard 네트워크 로드** — 빌드 CSS에 `@font-face` 92개 + `unicode-range` 서브셋이 들어간 것은 확인했다.
  실제 woff2가 브라우저에서 내려오는지는 네트워크 탭으로 봐야 한다.
- **그레이스케일 렌더** — 확정/예상, 예랑/예신 구분이 색 없이도 살아있는지.
